# منصة الإعفاءات الضريبية (Tax Exemption Invoice Platform)

تطبيق ويب حديث ومتكامل باللغة العربية لإدارة الفواتير المعفاة من الضرائب وتصديرها تلقائياً إلى كشوفات Excel جاهزة ومتوافقة تماماً مع متطلبات المعاملات الضريبية.

---

## 🚀 المميزات الرئيسية

* **واجهة مستخدم عربية بالكامل (RTL)**: تصميم عصري مريح وسهل الاستخدام للكوادر غير التقنية.
* **تعبئة تلقائية ذكية**: بمجرد اختيار الشركة أو الصنف، يتم تعبئة الرقم الضريبي، كود الصنف، ورقم الإعفاء تلقائياً.
* **إدارة البيانات الأساسية**: قسم خاص للتحكم في قائمة الشركات (الاسم، الرقم الضريبي) والمواد (الاسم، رمز البند الرئيسي، رقم الإعفاء) وتخزينها سحابياً.
* **إدارة الفواتير قبل التصدير**: إضافة الفواتير لجدول مؤقت ومراجعتها أو تعديلها أو حذفها قبل تحميل الملف.
* **تنسيق الإعفاءات التلقائي**: تحويل رقم الإعفاء تلقائياً إلى التنسيق المطلوب: `620/31/2/{رقم_الإعفاء}`.
* **تصدير Excel متوافق**: تصدير مباشر بأسماء الأعمدة والترتيب العربي الأصلي للملف المعتمد دون أي تغيير.

## 🛠️ متطلبات التشغيل والتهيئة

### 1. تهيئة قاعدة البيانات (Supabase)
1. افتح مشروعك في منصة **Supabase**.
2. اذهب إلى قسم **SQL Editor** ثم أنشئ استعلاماً جديداً.
3. انسخ محتويات الملف `database.sql` الموجود في جذر المشروع والصقه هناك، ثم اضغط **Run**.

### 2. إعداد ملف البيئة (Environment Variables)
1. افتح الملف `server/.env`.
2. استبدل القيم التجريبية ببيانات الاتصال الخاصة بمشروعك في Supabase:
   ```env
   SUPABASE_URL=https://your-project-id.supabase.co
   SUPABASE_ANON_KEY=your-supabase-anon-key
   PORT=5000
   ```

## 💻 طريقة التشغيل المحلية

في المجلد الرئيسي للمشروع (`e:\tax`)، اتبع الخطوات التالية:

### الخطوة الأولى: تثبيت الحزم البرمجية
قم بتشغيل الأمر التالي لتثبيت جميع المكتبات المطلوبة للواجهة والخلفية معاً:
```bash
npm run install-all
```

### الخطوة الثانية: بدء التشغيل التجريبي
قم بتشغيل الأمر التالي لتشغيل خادم الواجهة والخلفية معاً في نفس الوقت:
```bash
npm run dev
```

* ستفتح واجهة المستخدم على الرابط: `http://localhost:5173`
* سيعمل خادم البيانات على الرابط: `http://localhost:5000`
